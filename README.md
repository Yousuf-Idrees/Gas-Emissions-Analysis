# Gas-Emissions-Analysis
Analysis of CO₂ emissions from gas-powered cars using real-world data.

#  Gasoline Cars CO₂ Emissions Analysis

##  Project Summary
This project analyzes pollution from gas-powered vehicles using statistical methods. We applied data cleaning, visualization, and hypothesis testing to uncover key emission drivers.

##  Dataset
- **Source**: [Kaggle Dataset](https://www.kaggle.com/datasets/sakthinamasivayamk/fuel-consumption-and-co2-emissions-of-vehicles)
- Filtered to include only gas-powered cars (`Fuel Type` = X or Z).

- ##  Hypothesis Tests
1. CO₂: 4 vs 6 cylinders (Z-test)
2. Engine Size vs CO₂ (ANOVA)
3. Vehicle Class impact (ANOVA)
4. Fuel Type vs Class (Chi-Squared)
5. City vs Highway fuel (Z-test)


##  Key Findings
- Larger engines = more CO₂
- Manual cars emit slightly less
- Vehicle class & transmission affect emissions
- Insights support cleaner vehicle design
